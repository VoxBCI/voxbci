# Research

Background material supporting VoxBCI: literature, signal-processing notes, dataset
and protocol references, competitive landscape.

## Suggested layout

```
Research/
├── papers/        PDFs and citations
├── datasets/      links + licenses (never commit raw data)
├── notes/         experiments, findings, meeting summaries
└── references/    standards, SDK docs, BCI hardware specs
```

## Conventions

- One file per topic, dated: `notes/2026-11-11-ssvep-baseline.md`
- Cite sources with a link, not just a title.
- Raw datasets and large PDFs stay out of git — record the URL and license instead.
